# UI 文档

## 设计概念

产品应该像一间为语言学习改造过的字幕工作台：信息密度高、状态清楚、操作直接。用户每天来这里学习，所以界面优先服务于扫读、控制和沉浸练习，而不是讲故事式展示。

## 视觉系统

- 气质：克制、精密、偏工具型的学习控制台。
- 色彩：墨黑、纸白、暖琥珀、绿色和少量红色提醒。避免单一紫色、米色或常见深蓝仪表盘风格。
- 字体：关键学习数字和句子时刻使用带性格的衬线气质；操作区域使用清晰的无衬线栈。
- 形状：紧凑界面，圆角不超过 8px。
- 动效：只使用轻微状态过渡；学习控件要稳定，不制造跳动感。

## 布局规则

- 第一屏就是学习工作台，不做落地页。
- 使用全宽应用区域和工具面板，避免把页面区块做成营销式浮动卡片。
- 卡片只用于重复列表项、设置组和聚焦工具。
- 学习页优先级：媒体/播放状态、字幕句子、模式控制、录音/评分反馈。
- 工具栏按钮保持稳定尺寸，图标和标签变化不能导致布局位移。

## 组件规则

- 常用控制使用 lucide 图标：播放、暂停、跳转、循环、录音、词典、搜索、设置、上传、保存。
- 学习模式使用 tabs。
- 字幕、播放等二元设置使用 toggle 或 checkbox。
- 速度、循环次数、每日目标等数字设置使用 slider 或数字输入。
- 筛选和模式选择使用菜单或分段控件。

## 可访问性与响应式检查

- 文本不能溢出按钮或卡片。
- 移动端字幕仍要清晰可读。
- 主要控件触控区域至少 40px。
- 避免固定头部、底部工具栏和录音控件互相遮挡。
- 状态不能只依赖颜色表达。
